## 🚀 Práctica 1: Conversor de Unidades y Divisas Digitales

### 🎯 Objetivos de la práctica
* Aprender a crear y utilizar **variables** en Python.
* Interactuar con el usuario a través de la terminal (`input()` y `print()`).
* Realizar operaciones matemáticas básicas (multiplicaciones).
* Entender los tipos de datos numéricos (decimales o `float`).

### 📝 Instrucciones del reto
Debes escribir un programa en Python que realice dos tareas automáticas:
1. **Conversión económica:** Solicitar al usuario una cantidad en Euros (€) y calcular su equivalente en Dólares (\$) usando una tasa de cambio de **1.09**.
2. **Conversión informática:** Solicitar una cantidad de almacenamiento en Gigabytes (GB) y calcular cuántos Megabytes (MB) son (sabiendo que **1 GB = 1024 MB**).

## 🎯 Práctica 2: El Juego del Número Secreto

### 🎯 Objetivos de la práctica
* Aprender a importar herramientas externas usando `import`.
* Utilizar variables para almacenar números **enteros** (`int()`).
* Crear estructuras condicionales (`if` / `else`) para que el ordenador tome decisiones.
* Utilizar el comparador de igualdad (`==`).

### 📝 Instrucciones del reto
Debes programar un juego interactivo en Python. El programa debe seguir estrictamente estos pasos:
1. El ordenador debe elegir un número al azar entre el **1 y el 10** (pista: investiga cómo usar `import random` y `random.randint`).
2. El programa debe pedirle al usuario por teclado que intente adivinar el número.
3. **Condición final:** 
   * Si el usuario introduce el número correcto, el ordenador debe mostrar un mensaje de felicitación.
   * Si el usuario se equivoca, el ordenador debe mostrar un mensaje de error y decirle cuál era el número correcto.
