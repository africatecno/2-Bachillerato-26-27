## 🚀 Práctica 1: Conversor de Unidades y Divisas Digitales

### 🎯 Objetivos de la práctica
* Aprender a crear y utilizar **variables** en Python.
* Interactuar con el usuario a través de la terminal (`input()` y `print()`).
* Realizar operaciones matemáticas básicas (multiplicaciones).
* Entender los tipos de datos numéricos (decimales o `float`).

### 📝 Instrucciones del reto
Debes escribir un programa en Python que realice dos tareas automáticas:
1. **Conversión económica:** Solicitar al usuario una cantidad en Euros (€) y calcular su equivalente en Dólares (\$) usando una tasa de cambio de **1.09**.
2. **Conversión informática:** Solicitar una cantidad de almacenamiento en Gigabytes (GB) y calcular cuántos Megabytes (MB) son (sabiendo que **1 GB = 1024 MB**).
